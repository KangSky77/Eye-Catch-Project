## 결론

2026-10-03 추가로 북마크의 MIT·Apache 표기 자료와 177장을 합친 별도 **제공자 표기 기준 연구 후보**를 학습·비교했다. 원본 권한을 모두 확인한 후보와 구분하며, 현 서비스 모델은 교체하지 않았다. [961장 합본 실험 결과와 남은 권한](cataract-bookmark-merge-experiment-2026-10-03.md)을 참고한다.

후속 작업으로 Commons 사진 177장을 정리해 **별도 후보 3개의 학습·비교를 완료했다.** [실험 결과](licensed-cataract-experiment-2026-10-02.md)에 데이터와 조건, 고정 평가·앱 판독 결과, 남은 조건을 기록했다. 데이터 부족과 판독 안내 차이 때문에 서비스 v6는 교체하지 않았다. 현 모델·데이터는 보존했고 기존 자료의 미확정 권한은 계속 확인해야 한다.

라이선스 제한이 적다는 이유로 성능이 자동으로 낮아지는 것은 아니다. 남는 사진의 수, 독립적인 원본 그룹 수, 촬영 방식, 백내장 정도, 홍채 색, 반사와 다른 질환의 다양성이 영향을 준다. 기존 전체 데이터에서 권한을 확인한 사진이 몇 장 남는지는 아직 확정하지 않았다. 별도 후보의 소규모 실험 결과를 기존 데이터 전체 정제 후의 성능 하락률로 일반화하지 않는다.

## 데이터 규모와 성능에 영향을 줄 수 있는 부분

현 폴더 재계수: 정상 15,420장, 백내장 1,823장. 이것은 보관 파일 수이며 실제 train 표본 수가 아니다. 그룹 맵에는 17,233장·8,588그룹이 있다. 백내장 폴더 10장은 현재 그룹 맵에 없으므로 학습 준비 시 출처·라벨·분할을 확인해야 한다. 현 학습기는 맵에 없는 파일을 만나면 중단한다.

밝은 홍채 201장 중:

| 구분 | 장수 |
|---|---:|
| Public domain·CC0 | 34 |
| CC BY 계열 | 37 |
| CC BY-SA 계열 | 125 |
| FAL·Copyrighted free use | 5 |

CC0/PD/BY만 선택하면 이 보강 데이터에서 71장이 후보로 남는다. SA도 조건을 검토해 허용하면 125장을 더 고려할 수 있다. 라이선스 이름만으로 SA 전체를 버리면 알려진 밝은 홍채 오탐 보완 데이터가 크게 줄 수 있다. 실제로 v5 보강 전후, 같은 미학습 44장에서 오탐 38→8장이었다. 이 기록은 특정 하위집단의 개선 근거이며 실제 휴대폰 정확도를 뜻하지 않는다.

백내장은 정상보다 적다. 허락 불명 자료를 빼면서 백내장 정도·촬영 조건이 특정 유형으로 편중되지 않는지 확인한다. 익상편 226장을 빼면 다른 눈 질환을 백내장으로 오인하던 사례가 다시 늘 수 있어 별도 평가가 필요하다. 증강된 사진 수보다 원본 그룹 수를 기준으로 부족한 유형을 판단한다.

## 학습 후보의 기준

최종 사용 범위에 따라 아래 두 안을 선택할 수 있다. 사용자 정책은 아직 확정되지 않았다.

1. **공개·배포까지 고려:** 원본 권한과 조건을 확인한 PD/CC0, MIT, Apache 2.0, CC BY를 중심으로 구성한다. CC BY-SA는 별도 조건 검토 후 포함 여부를 결정한다. NC·Unknown·미확정 출처는 제외한다.
2. **비상업 연구·발표:** 위 자료에 명확한 CC BY-NC 또는 별도 연구용 허락 자료를 조건에 맞춰 추가한다. Unknown을 연구용 허락으로 간주하지 않는다.

어느 안이든 파일별 매니페스트에 파일 해시, 원본 URL·ID·버전, 저작자, 라이선스·증빙 위치, 확인일, 크롭·리사이즈 내역, 라벨, 원본 그룹, train/val/test 배정을 기록한다. 미확정 파일은 자동 포함하지 않는다. 같은 원본의 증강본·크롭·근접 중복도 함께 배정한다.

## 성능을 비교하는 절차

1. 현 v6 가중치와 메타데이터를 비교용으로 보존한다. 권한 검토 대상 데이터는 삭제하지 않고 별도 보관한다.
2. 출처를 확인한 이미지로 후보 데이터와 매니페스트를 만든다. 학습에 쓰기 전 평가 그룹을 고정한다. 현 모델의 train/val에 있던 그룹을 현 모델과 후보의 공정한 비교용 test로 쓰지 않는다.
3. 현 백내장 v6 가중치를 이어 학습하는 대신, 출처와 이용 조건을 확인한 초기 가중치에서 후보를 학습한다. 현 학습기는 ImageNet 사전학습 EfficientNet-B0에서 시작하므로 그 가중치·사전학습 데이터의 사용 조건도 별도 확인한다. 코드 라이선스가 곧 사전학습 데이터 라이선스는 아니다.
4. 같은 평가 이미지·전처리·운영 TTA·임계값으로 현 모델과 후보를 비교한다. 정제 후 임의로 다시 나눈 test 점수와 예전 test 점수만 비교하지 않는다.
5. 전체 정확도 외에 백내장 놓침(민감도/FN), 정상 오탐(특이도/FP), 위험·경계 안내, 밝은 홍채·익상편·반사·흔들림·실제 촬영 예시의 결과를 확인한다. 사진 입력 게이트의 통과율과, 통과한 사진의 판독 성능을 따로 기록한다.
6. 표본 수와 실제 오분류 장수를 함께 보고한다. 가능하면 고정 test에서 여러 학습 seed의 차이와 그룹 기준 불확실성도 확인한다. 후보 선택은 validation에서 하고 test로 반복 조정하지 않는다.
7. 성능과 라이선스 조건을 모두 만족하는 후보를 발표 모델로 결정한다. 부족하면 허용 데이터 보강·사용 범위 축소 또는 사진 AI의 연구 시제품 한계를 명시한다. 성능 때문에 허락 불명 모델을 공개용으로 자동 복귀시키지 않는다.

기존 `scripts/train_ai_v4.py`는 데이터 폴더와 그룹 맵 경로가 고정돼 있고 결과를 현재 모델 파일명에 저장한다. 별도 후보용 `scripts/licensed_cataract_pipeline.py`를 추가해 manifest·split·출력을 분리하고 기존 모델을 덮어쓰지 않도록 했다. 후보 작업에는 이 별도 도구를 사용한다.
