# 북마크 자료와 Commons 177장을 합친 백내장 후보 실험

확인일: 2026-10-03. 기존 서비스 v6 가중치·원본 데이터·177장 후보는 보존한다.

## 실험 범위와 권한 상태

사용자가 제안한 **북마크의 허용 라이선스 표기 자료 + Commons 177장** 조합으로 별도 후보를 실제 학습했다. 기존 v6 백내장 가중치를 이어 학습하지 않았다. 전이학습 후보와 사전학습 없이 시작한 후보를 각각 만들었다.

이번 합본은 **제공자 라이선스 표기를 기준으로 한 연구 실험**이다. MIT·Apache 표기는 확인했지만 업로더가 모든 원본 사진의 이용 허락을 부여할 권한을 갖는지 확인되지 않았다. 두 업로더가 같은 410장에 Apache와 CC BY-SA를 각각 붙인 사례와, MIT 표기 자료 안의 사진에 상업용 사진 사이트의 워터마크가 있는 사례도 확인했다. 따라서 이 모델을 ‘원본 권한이 모두 확인된 모델’, ‘라이선스 문제 완전 해결’, ‘발표·공개 배포 권한 확보’라고 표현하지 않는다. 워터마크를 지우거나 새로운 이름으로 권한 문제를 숨기지 않았다.

기존 Commons 파일별 조건 확인 정책을 MIT·Apache 이름만으로 자동 통과하도록 바꾸지 않았다. 합본은 manifest에 `publisher-declared-research; upstream permissions unresolved`를 명시한 경우에만 별도 연구 경로로 읽히며, 후보 메타데이터에도 이 상태를 남긴다. 저작자 칸의 Kaggle 이름은 **데이터 업로더**이며 원본 사진 촬영자를 확인했다는 의미가 아니다.

[Apache 공식 원문](https://www.apache.org/licenses/LICENSE-2.0)은 licensor를 저작권자 또는 권한을 받은 주체로 정의한다. [MIT 원문](https://opensource.org/license/mit)의 허용 조건과 [CC BY-SA 조건](https://creativecommons.org/licenses/by-sa/4.0/)을 확인하는 일과, 실제 사진의 허락 주체를 확인하는 일은 구분한다. ImageNet 사전학습 자료·가중치의 조건도 전이학습 후보에 별도로 남아 있다. 무작위 초기화 후보는 ImageNet 가중치를 쓰지 않지만 새 학습 사진의 미확정 권한까지 해결하는 것은 아니다.

## 정리와 라벨

합치기 전 177 + 672 + 410 = 1,259개 사진 파일이 후보였다. 1개는 디코딩되지 않아 제외했다. 기존 테스트의 근접 사진·같은 바이트 사진·기존 분할 연결 등 277개를 추가로 제외했다. 새 원본 그룹 대표 사진 325개를 검토 시트 6개에서 AI가 확인했고, 워터마크·명백한 합성·입력에 맞지 않는 사진 등 11개 그룹의 추가 사진 20개를 제외했다. 최종 **961장·480그룹**이다.

기존 177장의 train/validation/test 배정을 유지했다. 새 사진이 기존 test의 원본·근접 그룹에 속하면 학습에도 test에도 추가하지 않았다. 새 사진이 기존 train/val/test를 연결하는 경우 추가 사진을 제외했다. 라벨이 충돌하는 새 그룹을 정상 또는 백내장으로 임의 선택하지 않았다.

Roboflow의 `.rf` 파일명과 중첩된 `_JPG_jpg` 표기를 정규화해 같은 원본의 증강본을 묶었다. 모든 자료에 pHash 64bit 거리 6 이하의 근접 그룹 연결도 적용했다. 단, 크게 다른 크롭·회전·환자 단위 중복의 완전한 배제를 보장하는 방법은 아니다. 961장을 독립 환자 961명 또는 임상 정답 961개로 해석하지 않는다.

**`immature`는 정상 눈이 아니라 미성숙 백내장이다.** `immature`, `mature` 모두 백내장(1)으로 처리했다. 정상(0)은 기존 Commons 연구 라벨과 kershrita의 Normal 클래스에 따른다. AI의 사진 검토는 임상 라벨 확인을 대신하지 않으며 증강본 전체를 하나씩 임상 검수한 것은 아니다.

## 학습과 평가 원칙

- EfficientNet-B0, seed 42, batch 16, 224px와 기존 앱 정규화·학습 증강 사용.
- 전이학습 후보: ImageNet1K V1에서 head 5회 + 전체 미세조정 최대 20회.
- 무작위 초기화 후보: ImageNet 가중치 없이 전체 20회 이내 학습. 무작위 백본을 동결하는 head-only 단계는 생략.
- validation의 balanced accuracy + 0.25 × cataract F1으로 체크포인트 선택, early stopping 5회.
- test로 모델·임계값·체크포인트를 조정하지 않음. 현재 앱의 2/25/50점 임계값과 TTA 꺼짐 설정 사용.
- 기존 v6, 177장 전이학습 후보(seed42), 177장 무작위 후보(seed7), 합본 후보 2개를 같은 26장에서 비교.

기존 177장 실험 결과를 이미 확인한 뒤 진행한 후속 실험이다. 같은 26장을 보존해 자료 차이를 비교했지만 새로운 독립 최종 시험은 아니다. 백내장 test는 4장뿐이고 환자별 독립성·기존 v6의 크게 다른 크롭과의 중복도 확인되지 않았다. batch, 샘플링, 무작위 초기화 학습 단계도 이전 실험과 달라서 모든 차이를 데이터 장수 하나의 효과로 단정하지 않는다.

판독 서비스 비교는 별도 프로세스에서 실제 `vision.predict_cataract`를 호출하고 눈·사진 조건 검사와 크롭·방향 보정·반사·안정성 검사를 적용한다. 라이브 서버의 모델을 교체하지 않는다. 실제 휴대폰 촬영 또는 HTTP 업로드 전체 흐름을 새로 검증한 것은 아니다.

합본 전이학습 후보는 이전 177장 후보에서 정상 사진에 불확실 안내가 많던 현상을 개선했다. 무작위 초기화도 오탐은 줄었지만 최종 정상 안내는 적고 불확실·경계가 많아 현재 전이학습 후보를 대체할 수준의 근거는 부족하다.

## 최종 발표 전에 남은 조건

성능 비교와 원본 사진 권한 확인은 서로 대신할 수 없다. 북마크 출처의 원저작자·이용 허락·개별 사진 대응을 확보하거나, 해당 자료를 원본 권한이 확인된 자료로 대체해야 ‘라이선스 정리를 완료했다’고 설명할 수 있다. Commons의 SA 조건과 전이학습 가중치 조건도 공개 범위에 맞춰 정리한다. 새 모델은 이 조건 및 실제 촬영 검증을 충족한 뒤 적용을 판단한다.
