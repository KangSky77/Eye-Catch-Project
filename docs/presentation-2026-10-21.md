# 2026-10-21 발표 운영

2026-10-20 독립 부하 시험 후 실제 공개 사이트에 동시 체험 정원 **24명**을 적용했다. 25번째부터 대기 순번을 받고, 자리가 나면 기존 자동 입장 기능이 순서대로 입장시킨다. 화면을 열어두면 약 5초 간격으로 입장 상태를 확인한다.

- AI 서버 7대와 노트북의 사진 서버를 모두 실행하고 Tailscale 연결을 유지한다. 24명 권장은 이 구성을 기준으로 한다.
- 이 PC의 `.env`는 `MAX_ACTIVE_VISITORS=24`, `WAITING_ROOM_ENABLED=true`이다. 모델·질문 제한 시간·장비별 동시 처리 수는 시험한 설정을 유지했다.
- 공개 주소: `.env`의 `PRESENTATION_PUBLIC_URL` (공개 저장소라 주소는 적지 않는다)
- 실제 백엔드: `http://127.0.0.1:8002`, Uvicorn 프로세스 1개로 실행한다. 입장 대기 상태는 이 프로세스의 메모리에 있다.

프로젝트 폴더에서 실행:

```powershell
.\start-demo.ps1
```

실행기는 AI 장비와 사진 API를 점검하고 공개 주소의 입장 정원을 확인한다. `.env`를 변경해도 이미 실행 중인 서버의 정원은 자동으로 바뀌지 않는다.

## 적용 검증

- 공개 주소에 26개 독립 시험 세션을 연결했다. 24개는 즉시 입장, 나머지는 대기 1번·2번이었다.
- 대기자는 `/app` 직접 접근 시 대기 화면으로 돌아갔다.
- 입장한 시험 세션 하나가 나가자 대기 1번이 활성 상태가 되어 앱에 접근했고, 다음 대기자는 1번으로 이동했다.
- 기존 화면의 자동 상태 확인 및 입장 이동 스크립트가 공개 사이트에 제공되는 것을 확인했다.
- 시험 세션은 모두 해제했다.
- 서버 재시작 후 공개 주소에서 사진 검사 → AI 질문 2회 → 최종 소견까지 1회 완료했다. 두 질문 모두 AI 생성이었고 요청 오류나 기본 질문 대체가 없었다.
